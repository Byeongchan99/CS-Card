---
description: 대분류(+주제)를 받아 summary-notes/의 요약 노트를 직접 작성·정리한다
argument-hint: 대분류 이름 (선택: 다룰 주제 목록)
---

요약 노트는 공부 세션과 **분리된 트랙**이다. 카드와 연결하지 않으며, 카드가 없는 주제도
자유롭게 담는 독립 콘텐츠다. 퀴즈로 뽑아내는 게 아니라 **주제별로 정리해 쓱 보고 공부하는
노트**이고, Claude Code가 직접 작성한다.

입력: $ARGUMENTS

## 1. 대상 분야 확정

입력에서 대분류를 고른다 — 알고리즘, 자료구조, 운영체제, 유니티, C#, 디자인 패턴,
게임 수학·물리, 그래픽스. 대상 파일은 `summary-notes/<분야>.md`(파일명 규칙 적용:
`C#`→`C샵`, `게임 수학·물리`→`게임-수학-물리`, `디자인 패턴`→`디자인-패턴`).

다룰 주제가 함께 주어졌으면 그 주제들을 쓴다. 없으면 그 분야에서 얕고 넓게 훑을 주제
목록을 제안하고 확인받은 뒤 작성한다(카드가 없는 주제도 자유롭게 포함).

## 2. 작성·정리

`summary-notes/<분야>.md`에 항목을 **직접 작성**한다.

- 기존 항목과 주제가 겹치면 **한 항목으로 통합**한다(중복 금지). 한쪽에만 있는 정보를 흡수.
- 새 주제는 관련 항목 옆에 배치한다. 페이지는 평평한 `##` 구조를 유지하되(그룹 헤딩을
  넣지 않는다) 배열 순서를 주제별로 인접하게 잡아 목차가 흐름으로 읽히게 한다.
- 항목이 다른 분야에 더 맞으면 그쪽 파일로 넣고 보고한다.

## 3. 형식 — 쓱 보고 공부하는 노트

- 항목마다 `##` 헤딩 + 2~4문장 요약. 짧고 담백하게.
- A vs B 형태의 비교는 표로.
- 종결어미를 생략한 간결체 (심화 노트의 `~다` 문체와 다르다).
- **콜아웃은 쓰지 않는다.** 강조할 내용은 문장에 녹인다.
- 세션 부기 금지 — `====` 구분선, 번호 매김, "N일차", "퀴즈 N번", "새 개념 —" 접두사.
- 카드 `[[위키링크]]`를 넣지 않는다(카드와 연결하지 않는 것이 원칙).

## 4. 다이어그램 넣기

흐름·구조·전이가 있는 항목엔 다이어그램을 넣는다. 요약이라 얕게 훑는 용도이니 **맞는
항목에만**, 노트당 과하지 않게. 이미지 파일이 아니라 텍스트로 저장한다 — Quartz가 렌더하고
라이트/다크 테마에 자동 대응한다. 항목 문단 바로 뒤에 배치한다.

- **Mermaid** (` ```mermaid ` 코드펜스) — 트리·상태 전이(FSM)·파이프라인·DAG·pub-sub 등
  구조/흐름에. 한글 노드 ID는 파싱이 깨질 수 있으니 ASCII ID + 따옴표 라벨(`sock["양말"]`)로
  쓴다(숫자 ID는 안전). 노드가 붐비면 `%%{init: {'flowchart': {'rankSpacing': 55}}}%%`로
  간격을 넓히고 `<br/>`로 노드 텍스트를 줄인다. 라벨 배경·테두리 칩 스타일은 사이트 CSS
  (`custom.scss`, `mermaid.inline.ts`)가 처리하므로 노트에서 손대지 않는다.
- **인라인 SVG** (마크다운 안 raw `<svg>`, **한 줄로** 쓰고 앞뒤 빈 줄) — 벡터·충돌·라이팅·
  각도 같은 기하학적 그림에. 선·글자는 `fill/stroke="currentColor"`로 테마 대응, 강조는
  파랑 `#4f83e0`·코랄 `#e2574c`·초록 `#3fae7a`(라이트·다크 양쪽에서 읽힘). 화살표 marker는
  표준(`M0,0L6,3L0,6Z` refX=6 refY=3 orient=auto)으로 통일해 방향 깨짐을 피하고, 좌표는
  라벨·호가 선 밖으로 삐져나오거나 겹치지 않게 잡는다.

로컬에 Node가 없어 다이어그램 렌더는 눈으로 못 본다. 필요하면 배포 후 브라우저로
`https://byeongchan99.github.io/CS-Card/...`를 열어 확인한다.

## 5. 검증 후 커밋

- `grep "복습 포인트\|\[!tip\]" summary-notes/<분야>.md` → 0건
- 세션 부기 잔존 0건(`====`, `일차`, `퀴즈 \d+`)
- 파일명 금지 문자 없음
- 한 줄에 물결(`~`)이 2개면 GFM이 취소선으로 오인한다. 범위 표기는 `-90~90` 대신
  `−90°에서 +90°`처럼 물결 없이 쓴다

변경 요약(분야, 추가·통합한 항목 수)을 먼저 보여준 뒤 커밋·푸시하고 GitHub Actions 결과를
확인한다.
