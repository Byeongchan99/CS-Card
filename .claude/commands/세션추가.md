claude.ai 공부 세션이 낸 산출물을 저장소에 반영한다. 규칙은 `CLAUDE.md`와
`docs/공부세션-지침.md`를 따르고, 아래 순서를 건너뛰지 않는다.

붙여넣은 산출물: $ARGUMENTS

## 1. 분류

붙여넣은 덩어리를 심화 노트 / 카드 / index.md 줄로 나눈다. 산출물이 일부만 왔으면
(예: 카드만 있고 심화 노트가 없음) 그 사실을 먼저 알리고, 있는 것만 처리할지 묻는다.

## 2. 배치

- 카드 → `cards/<파일명>.md`
- 심화 노트 → `deep-notes/<파일명>.md`

파일명은 공백을 하이픈으로 바꾸고 금지 문자 `#` `.` `=` `/` `:` `?` `%` `&` 를 치환한다.
`C#` → `C샵`, `A*` → `A스타`, `UnityEngine.Pool` → `UnityEngine-Pool`.
`title`(frontmatter)에는 원래 표기를 그대로 써도 된다.

## 3. 체인 판단 — 새 노트인가 덧붙이기인가

심화 노트의 `chains` 루트가 **이미 다른 노트에 걸려 있는지** 먼저 확인한다
(`deep-notes/*.md`의 `chains`·`cards`를 전부 훑는다).

- 걸려 있으면 → 새 노트를 만들지 말고 **그 노트 본문 끝에 `##` 절을 덧붙인다.**
  `chains`가 루트만 가리키고 빌드가 parent 트리를 펼치므로 frontmatter는 손대지 않아도 된다.
- 단 대상 노트의 `##` 소제목이 이미 8개를 넘으면 주제를 쪼개 새 노트로 낸다.
  이때 새 노트는 `chains` 대신 `cards`에 이번 카드만 적어 자동 전개를 막는다.

## 4. 검증 — 하나라도 실패하면 커밋하지 말고 보고한다

로컬에 Node가 없으므로 빌드로는 못 잡는다. 반드시 정적으로 대조한다.
PowerShell로 읽을 때는 `[System.IO.File]::ReadAllText($path, [System.Text.Encoding]::UTF8)`를
쓴다 — Windows PowerShell 5.1의 기본 인코딩으로 읽으면 한글이 깨져 비교가 전부 실패한다.

- 심화 노트의 `chains`·`cards` 값이 실제 카드 **파일명 또는 title**과 일치하는가
- 카드·노트 본문의 `[[위키링크]]`가 전부 실제 카드로 해석되는가.
  해석 안 되는 링크는 **스텁 카드를 만들지 말고** 링크 마크업만 벗겨 일반 텍스트로 두고 보고한다
- 카드의 `parent` 값이 해석되는가
- 파일명에 금지 문자가 없는가
- `related`가 대괄호 없는 문자열 배열인가 (`[[...]]`가 섞이면 안 된다)

## 5. index.md 갱신

- 카드 표에 줄 추가: `제목 | 대분류 | 세부태그 | result | status`
- `## 심화 노트` 섹션 갱신: `제목 | 대분류 | 다루는 루트 카드`

이 파일은 claude.ai 프로젝트 지식에 연동되어 중복 출제와 중복 해설을 막는 데 쓰인다.
빠뜨리면 다음 세션이 같은 주제를 또 낸다.

## 6. 보고 후 커밋

변경 요약(추가된 카드·노트, 덧붙인 절, 검증 결과, 발견한 문제)을 먼저 보여준 뒤
커밋·푸시한다. 푸시 후 GitHub Actions 결과를 확인하고 실패하면 로그를 본다.

카드 본문의 내용 오류는 **수정하지 말고 보고만 한다.** 파일 삭제도 명시적 요청이 있을 때만.
