## 질문
2D 벡터 `a = (ax, ay)`, `b = (bx, by)`를 외적하면 부호를 보는 스칼라 값이 나온다. 이 값을 `ax, ay, bx, by`로 쓰면 무엇인가?

## 핵심 답변
`ax·by - ay·bx`다. 2D 벡터를 z=0인 3D 벡터 `a = (ax, ay, 0)`, `b = (bx, by, 0)`로 올려 외적하면 결과는 `(0, 0, ax·by - ay·bx)`가 되어 z성분만 남는다.

## 정리
### 내부 동작
3D 외적의 x성분 `ay·bz - az·by`와 y성분 `az·bx - ax·bz`는 `az = bz = 0` 때문에 전부 0으로 죽는다. z성분 `ax·by - ay·bx`만 살아남는다.

```
a = (ax, ay, 0)
b = (bx, by, 0)
a × b = (ay·0 - 0·by,  0·bx - ax·0,  ax·by - ay·bx)
      = (0, 0, ax·by - ay·bx)
```

### 실무(게임 개발)에서 생기는 문제와 해결
2D 게임에서 굳이 벡터 외적을 부르지 않고 `ax·by - ay·bx` 한 줄로 좌우 판정을 한다. Unity에서 `Vector2` 사이에는 `Vector3.Cross`가 바로 안 되므로 이 식을 직접 쓰거나, z=0인 `Vector3`로 올려 `Cross`의 z를 읽는다.
