## 질문
아래 반암시적 오일러 적분에서 초기값은 position = 0, velocity = 0이다. 기기 A는 dt = 1.0으로 1회, 기기 B는 dt = 0.5로 2회 Step을 호출한다. 각 기기의 최종 position은 얼마이고, 해석해와 비교하면 어느 쪽이 더 가까운가? 이 차이는 부동소수점 반올림 때문인가?

```csharp
const float gravity = -10f;

void Step(float dt)
{
    velocity += gravity * dt;
    position += velocity * dt;
}
```

## 핵심 답변
A는 -10, B는 -7.5이고, 해석해 ½·a·t² = -5에 B가 더 가깝다. 이 예제의 값은 모두 이진 부동소수점으로 정확히 표현되므로 반올림은 한 번도 일어나지 않는다. 차이는 오일러 적분이 한 스텝 동안 속도를 일정하다고 가정하기 때문에 생기는 절단 오차다. 스텝을 잘게 나눌수록 이 오차가 줄어들기 때문에, 같은 1초라도 dt가 다르면 결과가 다르다.

## 정리
### 내부 동작
```
dt = 1.0, 1회  : v = -10, p = -10
dt = 0.5, 2회  : v = -5,  p = -2.5  →  v = -10, p = -7.5
해석해         : p = -5
```

### 왜 그런가
실제 속도는 스텝 안에서도 계속 변한다. 그런데 오일러 적분은 스텝 끝의 속도 하나로 그 구간 전체의 이동을 계산한다. 그래서 스텝이 클수록 실제 궤적에서 더 멀리 벗어난다.

### 흔한 오해/함정
"실수 정밀도가 부족해서 결과가 갈린다"는 설명은 이 예제에 맞지 않는다. 정밀도가 무한해도 dt가 다르면 결과는 다르다.
