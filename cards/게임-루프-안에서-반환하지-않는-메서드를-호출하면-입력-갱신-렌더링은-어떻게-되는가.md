## 질문
메인 게임 루프(입력 처리 → 객체 갱신 → 렌더링)의 객체 갱신 단계에서 어떤 객체가 무한 루프 안에서 위치만 바꾸는 메서드를 호출했다. 이후 입력 처리, 다른 객체들의 갱신, 렌더링은 언제 실행되며, 플레이어 화면에는 무엇이 보이는가?

## 핵심 답변
메서드가 반환되기 전까지 같은 스레드의 나머지 작업은 실행되지 않는다. 이번 프레임의 입력 처리와 그 객체보다 앞서 갱신된 객체들은 이미 실행되었다. 하지만 뒤에 있는 객체 갱신과 렌더링은 실행되지 않고, 다음 프레임도 시작되지 않는다. 내부 좌표가 아무리 바뀌어도 화면에 반영할 렌더링이 오지 않으므로 화면은 마지막 프레임에서 굳는다. 입력에도 반응하지 않고, 창 메시지 처리가 멈춰 OS가 응답 없음으로 표시한다.

## 정리
### 내부 동작
```text
frame N:  Input → Update(A) → Update(B: 무한 루프) ─┐
                                                      └─ 영원히 여기
          Update(C), Render, frame N+1  →  실행되지 않음
```

### 왜 그런가
게임 루프는 협력적 구조다. 각 객체가 자기 몫을 하고 스스로 제어권을 돌려준다는 전제 위에서만 돌아간다. 선점해서 끊어 주는 장치가 없다.
